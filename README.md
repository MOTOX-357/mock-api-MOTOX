# GSK Rapid Support Platform (`ea7327u201621873`)

## Overview
This is an Angular 21 application developed for GSK to manage equipment maintenance issues and service orders. The project follows a domain-driven, layered architecture.

## Features
- Issue Analytics Dashboard with real-time cost calculation.
- New Issue registration with automatic Service Order generation.
- Support for English and Spanish (i18n).
- Responsive UI based on Angular Material.
